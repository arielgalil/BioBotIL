# Product Guidelines - BIO-Bot

## Visual Identity & UI Style
- **Color Palette:** A nature-inspired "Bio" green theme.
    - Primary: `#10b981` (Bio-500)
    - Background: `slate-50` (Light), `gray-900` (Dark)
    - Accents: Gradient from `bio-400` to `bio-600` for primary branding elements.
- **Typography:** Modern, clean Hebrew-supporting fonts.
    - Sans: `Rubik` (for main body and chat)
    - Display: `Heebo` (for headers and titles)
- **Design Elements:**
    - Rounded corners (2xl/xl) for cards and input areas.
    - Backdrop blur effects on the header for a modern, glassmorphism feel.
    - Subtle drop shadows for depth on interactive elements.

## User Experience (UX)
- **RTL Support:** The interface is built from right-to-left to serve the primary Hebrew-speaking audience.
- **Micro-interactions:** Smooth transitions (`duration-300`) between light/dark modes and hover states on buttons.
- **Responsive Layout:** A centered, max-width (`max-w-4xl`) container that feels like a modern chat application on both desktop and mobile.
- **Immediate Feedback:** Real-time streaming for chat responses and clear "Loading" states.

## Tone & Voice
- **Persona:** Friendly, encouraging, and knowledgeable "BIO-Bot".
- **Language:** Professional yet accessible Hebrew.
- **Structure:** Scientific explanations should be broken into digestible parts, avoiding large walls of text. Key biological terms should be **bolded** for emphasis.
